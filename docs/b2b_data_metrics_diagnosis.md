# B2B 经营数据指标与诊断知识库

## 1. 为什么要做经营诊断

B2B 商家运营需要通过数据判断问题，而不是只凭经验。经营诊断可以帮助商家发现商品供给、流量、询盘、转化、履约和售后中的瓶颈。

## 2. 常见经营指标

- 商品完整度：标题、主图、属性、详情页是否完整。
- 曝光量：商品被采购商看到的次数。
- 点击率：点击量 / 曝光量。
- 询盘率：询盘数 / 访问量。
- 回复率：已回复询盘数 / 总询盘数。
- 平均响应时长：商家回复采购商的平均时间。
- 报价转化率：报价后进入样品、合同或订单阶段的比例。
- 履约准时率：按约定时间发货或交付的比例。
- 售后率：售后订单数 / 总订单数。

## 3. 常见问题诊断

如果曝光低，可能是标题关键词不足、商品数量少或活动参与不足。如果点击率低，可能是主图、价格或标题吸引力不足。如果询盘率低，可能是商品详情不完整、起订量不清晰或信任信息不足。

如果回复率低或响应慢，可能影响采购商继续沟通。如果售后率高，可能说明质量、物流、包装或商品描述存在问题。

## 4. AI 辅助经营诊断

AI 可以根据指标生成诊断摘要，例如“该商家曝光正常但询盘率偏低，建议优先优化主图、详情页和起订量说明”。AI 也可以自动生成运营跟进任务。

## 5. 诊断建议的边界

AI 生成的经营建议必须说明依据，例如“点击率低于类目均值”或“商品属性缺失较多”。没有数据依据时，应输出“需要补充数据后判断”。
