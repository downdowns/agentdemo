# B2B 商家运营知识库

## 1. 商家运营的核心目标

B2B 平台的商家运营目标是提升商家的商品供给质量、询盘转化效率、交易履约能力和长期经营活跃度。运营团队通常围绕商家成长、商品优化、流量获取、客户响应和交易转化开展工作。

## 2. 商家分层运营

平台可以根据经营阶段、商品数量、成交能力、履约稳定性和服务质量，将商家划分为新商家、成长商家、成熟商家和重点商家。

- 新商家：重点完成基础资料、店铺装修、商品发布和首批曝光。
- 成长商家：重点提升商品质量、询盘回复率、报价效率和转化能力。
- 成熟商家：重点关注客户复购、供应链稳定性、活动参与和品牌建设。
- 重点商家：重点提供定制化运营策略、行业趋势分析和平台资源协同。

## 3. 高频重复工作

商家运营中存在大量重复性工作，例如检查商品标题、主图、属性和详情页是否完整，回复入驻、商品发布、活动报名和售后规则问题，整理商家经营数据并生成运营建议。

这些工作适合通过 AI 助手、知识库问答、自动化表单和 Agent 工作流进行提效。

## 4. AI 可以帮助商家运营做什么

AI 可以承担以下辅助能力：

- 规则问答：回答入驻、商品发布、活动、售后等规则问题。
- 内容优化：根据商品信息生成或优化标题、卖点、详情描述和客服话术。
- 经营诊断：结合商品完整度、询盘回复率、转化率等指标生成运营建议。
- 任务提醒：根据商家状态提醒补充资料、优化商品或处理售后。
- 工单分流：根据问题类型将商家咨询分流到规则解释、人工客服或运营跟进。

## 5. 风险边界

商家运营 AI 助手应优先基于平台规则和知识库回答问题，不能编造不存在的政策。涉及处罚、退款、合同、资质审核等高风险问题，应提示用户以平台官方规则或人工审核结果为准。
