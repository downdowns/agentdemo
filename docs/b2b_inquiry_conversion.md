# B2B 询盘响应与转化知识库

## 1. 询盘转化的含义

询盘转化是指采购商从发起咨询到获得报价、样品、合同或订单的过程。B2B 平台中，询盘响应速度、报价准确性和专业沟通会直接影响成交概率。

## 2. 影响询盘转化的关键因素

- 回复速度：采购商通常会同时咨询多个供应商，响应慢会降低机会。
- 信息完整度：报价需要包含规格、起订量、交期、付款方式和物流说明。
- 专业程度：回复应理解采购需求，避免只发送模板话术。
- 跟进节奏：对高意向采购商应持续跟进样品、报价和合同。
- 信任建立：通过资质、案例、质检、产能和售后能力增强信任。

## 3. 标准询盘处理流程

典型流程包括识别采购需求、确认规格数量、给出初步报价、说明交期和起订量、提供样品或案例、跟进采购决策并记录结果。

## 4. AI 辅助询盘场景

AI 可以辅助完成：

- 识别询盘意图，例如询价、定制、样品、售后或物流问题。
- 根据商品资料生成初步回复模板。
- 提醒商家补充规格、数量、交期、付款方式等关键信息。
- 根据历史对话生成跟进建议。
- 将高意向询盘标记给人工销售优先处理。

## 5. 不适合完全自动化的情况

涉及大额订单、特殊定制、合同条款、跨境结算、质量争议和客户投诉时，不建议完全自动回复，应由人工销售或运营介入。
