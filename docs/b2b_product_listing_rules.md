# B2B 商品发布与信息质量规则知识库

## 1. 商品发布的核心目标

商品发布的目标是让采购商快速理解商品是什么、适合什么场景、有什么规格、如何报价和如何交付。高质量商品信息可以提升搜索曝光、询盘转化和交易信任。

## 2. 商品标题规范

商品标题应包含核心品类、关键规格、材质、用途或适用场景。标题应避免堆砌无关关键词、夸大宣传、使用违规词或与商品实际不符。

示例结构：

```text
核心品类 + 材质/规格 + 使用场景 + 供应方式
```

## 3. 商品属性完整度

商品属性包括品牌、型号、材质、尺寸、颜色、产地、包装、起订量、交期、定制能力等。属性越完整，采购商越容易筛选和比较商品。

## 4. 主图和详情页要求

主图应清晰展示商品主体，避免水印、遮挡、无关背景和虚假效果。详情页应说明商品特点、规格参数、应用场景、生产能力、质检流程、包装物流和售后服务。

## 5. 常见问题

商品信息质量低常见原因包括标题过短、属性缺失、图片不清晰、价格区间不合理、详情页没有规格参数、没有说明发货周期或售后政策。

## 6. AI 可以如何辅助商品发布

AI 可以根据基础商品资料生成标题、卖点、详情页结构、关键词建议和属性补全提醒。AI 也可以对已发布商品进行质量检查，指出标题缺失、属性不完整、详情页信息不足等问题。

## 7. 风险边界

AI 生成的商品内容必须基于真实商品信息，不能虚构认证、销量、产能、品牌授权或质量承诺。涉及医疗、食品、化工等高风险类目时，应遵循平台规则和行业监管要求。
